# Calculadora de desconto

Atividade de JavaScript: formulário com input numérico, condicionais `if / else if / else` e exibição do valor original, desconto e total.

- Compra maior que R$ 500: 10% de desconto.
- Compra maior que R$ 100 até R$ 500: 5% de desconto.
- Compra até R$ 100: sem desconto.

Interface desenvolvida com auxílio de IA. Lógica em JavaScript puro.

## Executar
Abra `index.html` no navegador. Não há dependências.
